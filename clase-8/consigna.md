## Ejercicio — Biblioteca

Crear una base de datos llamada biblioteca y una colección libros.

- Cargar 5 libros con los campos: titulo, autor, precio y disponible.

Luego realizar estas operaciones:

1. Mostrar todos los libros.
2. Buscar los libros de un autor determinado.
3. Buscar los libros con precio mayor a $20.000.
4. Cambiar el precio de un libro.
5. Eliminar un libro.
